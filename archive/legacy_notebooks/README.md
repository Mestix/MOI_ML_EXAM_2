# Legacy notebooks

Deze map bevat eerdere versies van de notebooks die tijdens het onderzoek zijn gebruikt.
Ze laten zien welke experimenten en verkenningen voorafgaand aan de definitieve analyse
zijn uitgevoerd.

De opgeslagen notebookoutputs zijn verwijderd, zodat oude resultaten niet per ongeluk
als definitieve resultaten worden geïnterpreteerd. De actuele code staat in de hoofdmap
van de repository. De definitieve resultaten en figuren staan in `results/` en `figures/`.
